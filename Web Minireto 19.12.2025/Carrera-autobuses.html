Carrera de Autobuses

Juego desarrollado en Java

  • INICIO

Descripción

Carrera de Autobuses es un juego en el que dos autobuses compiten avanzando de forma aleatoria hasta alcanzar la meta.

Características

  • Programación orientada a objetos
  • Uso de clases y métodos
  • Avance aleatorio
  • Simulación de carrera

El juego permite comprender conceptos básicos de Java como atributos, métodos y control de flujo.
