Las Damas

Juego de mesa clásico en Java

  • INICIO

Descripción

Las Damas es una implementación del clásico juego de mesa para dos jugadores, desarrollada utilizando Java y programación orientada a objetos.

Características

  • Tablero de juego
  • Turnos entre jugadores
  • Movimientos válidos
  • Uso de clases para fichas y tablero

Este juego permite practicar estructuras de control, clases, métodos y lógica de juego.
